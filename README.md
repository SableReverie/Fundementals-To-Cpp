# Fundamentals to C++

A personal learning repository documenting my journey from the fundamentals of C++ to graphics programming.

This project serves as a reference for the concepts, exercises, and techniques I learned while building a strong foundation in C++ and gradually applying those skills to more advanced graphics and rendering topics. It is organized as a collection of notes, examples, and implementations that reflect my progress from beginner-level programming to more complex game and graphics-related development.

## Purpose

This repository is meant to:
- Reinforce core C++ fundamentals
- Document key programming concepts and best practices
- Track my learning progression
- Build practical examples and small projects
- Bridge the gap between theory and graphics programming

## Topics Covered

- Variables, data types, and operators
- Control flow and loops
- Functions and modular programming
- Arrays, strings, and pointers
- Object-oriented programming
- Classes, constructors, and inheritance
- Memory management
- STL containers and algorithms
- File I/O
- Mathematics for graphics
- Rendering concepts
- Graphics programming basics
- Game development ideas and practical applications

## Learning Journey

This repository reflects my growth from:
- learning the basics of C++
- understanding programming logic and problem solving
- implementing core concepts in real code
- applying those concepts to graphics and visual programming challenges
